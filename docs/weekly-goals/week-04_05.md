## 2. Backend Refactor (Domain First)

- Garantir separação correta das camadas:
  - routes → validação
  - services → lógica com domínio válido
  - repo → apenas domínio

- Mover validações para as **routes**
- Garantir que:
  - services não recebem `String`, `Int`, etc.
  - recebem apenas tipos de domínio:
    - Username
    - Password
    - EndpointUrl
    - IntervalSeconds

- Remover lógica indevida:
  - criação de user default → mover para repository (memory)

###### Deliverable:
- Validação centralizada nas routes (boundary do sistema)
- Conversão explícita de DTO -> Domain nas routes
- Services recebem e trabalham com tipos de domínio:
  - Username
  - Password
  - EndpointUrl
  - IntervalSeconds
- Eliminação de validações redundantes fora do domínio
- Introdução de value objects para garantir consistência
